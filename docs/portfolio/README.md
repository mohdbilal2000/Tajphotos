# Portfolio plan (archived from the `claude/elegant-newton` branch, Sept 2026)

An earlier plan to run six sites, one per domain, each a genuinely different product (portrait
shoots, photo tours, prints and licences, shared day trips, guide-only tours). It was **not merged**:
its code replaced the price table and enquiry form with quote-only funnels and rewired every page
for multiple brands.

Kept for reference only. The current approach is one authority site, tajphotos.com, with the spare
domains redirecting into it; see `docs/strategy/exponential-plan.md`. Revisit this plan only when a
second product has its own operations (different team, different deliverable), not just a different
domain name.
